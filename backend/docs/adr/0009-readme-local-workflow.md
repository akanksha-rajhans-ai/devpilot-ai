# ADR 0009: README & Local Development Workflow

## Status

Accepted

## Context

DevPilot AI needs a clear repository entry point that explains the project purpose, setup, current architecture, local runtime, CI, constraints, and roadmap.

## Options Considered

1. Rely only on code and commit history
2. Document setup in scattered notes
3. Use a root README as the main onboarding document
4. Create a full documentation site immediately

## Decision

Create a root README as the primary onboarding and local development guide.

## Consequences

The project is easier to understand, run, and present. The README must be kept current as features evolve. More detailed documentation can be added later when the platform grows.
